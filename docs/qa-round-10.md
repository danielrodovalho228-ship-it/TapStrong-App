## Daniel's decisions (round 10)

1. **Separate counters:** wrong PINs lock only the PIN; wrong email codes have their own counter and lockout (5 wrong → 15 min). A teen typing wrong PINs must never block the owner's email reset. Both counters in the secure store and reported to the server.
2. **Repair counts only toward the muscle cap, not the painful-joint budget.** Repair sets enter the 20/14/12/10 per-muscle history, but not the 12-set joint budget (they are therapeutic). Regular and finisher work still count toward the joint budget. Test: 2 knee Repair sessions in a week do not block regular knee-loading work.
3. **Joint budget counts only exercises that MOVE the painful joint.** Knee: squats, lunges, step-ups, leg extension/curl, split squats and similar count; moves where the knee only stabilises or holds still (standing shrugs, farmer hold/walk, glute bridge/hip thrust, bridge floor press, RDL-type holds, lateral walk if knee is isometric) do not. Use the existing tag detail (e.g. `knee:isometric`/stabiliser) — clean up the tags where needed and apply the same rule to shoulder, lower back, hip, elbow/wrist and neck. Tests per joint with one moving and one isometric example.
