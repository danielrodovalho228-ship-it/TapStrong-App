## Answers to the Phase 19 open questions

1. Short workouts vs the Phase 13 decision — **Daniel decided: keep the Phase 13 rule (exercise count as chosen, "Add 1 exercise?" stays) and use the extra time for sets.** Measured: a 60-min gym user gets 34–43 min, and 45/60/90 min give identical sessions. Fix: after building the session, if the estimate is under ~85% of the chosen time, add one set at a time to the main (non-warm-up, non-mobility) moves, round-robin, up to 4 sets per move for adults 18–59 (3 for teens, 60+ and joint-care; no change in deload weeks), respecting weekly-set caps and recovery rules; stop at ~85%. Never add exercises this way. 30 min keeps the current trim. The estimate on the list must match. Tests: 45 < 60 < 90 min give increasing set counts for the same user; a 60-min gym user lands at 48–54 min; teens/60+ never exceed 3 sets; deload unchanged.
2. Small-gym 3-exercise pull swing — not accepted as is: it comes from the 8-day window and the `pushNow() < 2` guard (see P2). Fix those; then 80–125% on calendar weeks is fine as long as the strict 7-day rolling window stays ≥ 90%.
3. React #418 on web — accepted for now, but fix the clock-based text part (R8-04).
4. Spreadsheet formulas — fine; rebuild the sheet after R8-06.
